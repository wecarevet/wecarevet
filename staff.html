💻 원내 PC — 즐겨찾기

  1. Chrome은 주소창 오른쪽 ☆ 클릭 → 이름을 원내 도구로 저장
  2. 저장한 뒤 북마크 관리자에서 북마크 바에 표시를 켜면 화면 위에 항상 남습니다
  3. Ctrl + D(Mac은 ⌘ + D)만 눌러도 저장됩니다

📱 휴대폰 — 홈 화면에 추가

  • Android: Chrome 우측 상단 ⋮ → 홈 화면에 추가
  • iPhone: Safari 하단 공유 → 홈 화면에 추가
